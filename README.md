# Retail Pricing & Promotion Analysis (Excel)

## Objective
Analyze the impact of pricing, discounts, promotions, and advertising on customer footfall and return rates.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Correlation Analysis

## Key Analyses
- Pricing vs Demand
- Discount & Promotion Effectiveness
- Advertising Spend ROI
- Customer Sentiment vs Return Rate
- Correlation & Driver Analysis

## Dataset
Synthetic retail dataset with 15,000 records and 11 numeric features.
